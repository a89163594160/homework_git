# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект содержит автоматизированные тесты для проверки функциональности проекта "Yougile":
 - Авторизация
 - Добавление/изменение проектов
 - Добавление/изменение задач

### Для запуска тестов необходимы пароль и логин от личного кабинета "Yougile":
MY_LOGIN = логин
MY_PASSWORD = пароль

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Requests**: Библиотека для работы с HTTP-запросами.
4. **Pytest**: Фреймворк для написания и запуска тестов.
5. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

#### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure 

1. Установите необходимые зависимости:
   pip install -r requirements.txt

2. Запустите тесты с генерацией отчета Allure:
   pytest --alluredir=./allure-results

Эта команда запустит все тесты и сохранит результаты в директорию `./allure-results`.
---

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   allure serve ./allure-results
Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:

**test_API:** API - тестирование
- "Получение ключа авторизации с валидным логином и паролем."
- "Получение списка проектов."
- "Добавление задачи."
- "Удаление задачи."
- "Негативный тест: добавление задачи с пустым заголовком."
- "Негативный тест: получение списка задач без токена."

**test_UI:** UI-тестирование
- "Авторизация в личном кабинете."
- "Редактирование профиля: установка статуса"
- "Добавление нового проекта"
- "Редактирование проекта: перемещение в архив"
- "Добавление списка задач."

Отчет о тестах содержит:

   - **Название теста**
   - **Описание теста**
   - **Шаги теста**
   - **Результат**:Успешное выполнение или ошибка с указанием ожидаемого и фактического результ
